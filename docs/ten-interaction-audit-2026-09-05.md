# Ten-mechanic interaction audit, 2026-09-05

This slice improves ten existing entries. It adds no registry entries and does not claim ten newly complete mechanics.

| Entry | Executable improvement | Remaining limitation |
| --- | --- | --- |
| Rage | Static damage survives either Savage Attacker choice; Athletics gets Strength advantage; extension respects next-turn order, enemy attacks, and pending choices | Broader import and adjudication support remains outside this slice |
| Savage Attacker | Unarmed strikes and fixed damage do not consume the weapon reroll; critical dice retain static bonuses | Uses the verified roster's registered weapon identities |
| Surina's 2014 Lay on Hands | Each selected poison costs five points; other poison sources and their Poisoned condition remain; no blanket 2024-style removal | Afflictions require explicit source registration |
| Detect Magic | Spell effects are explicitly magical; nonmagical modifiers produce no aura; point effects use map points; blinded and invisible visibility is respected | Barrier materials/thickness, effect schools, ritual casting |
| Large Form | Full footprint blocks forced movement and incurs difficult-terrain cost | Anchor-based targeting/area geometry and squeezing |
| Cleira's Charm Person | Charmed creatures cannot directly target their charmer with harmful spells; rejection spends nothing | Social advantage, friendly targeting, explicit fighting relationships |
| Pharos's Charm Person | Same harmful-spell restriction, preserving 2014 provenance | Same remaining gaps |
| Vicious Mockery | Deafened targets cannot be affected; invalid choice preserves the Action | Verified level-one spell profile |
| Chill Touch | Healing prevention attaches even when damage reduces the target to zero; expires normally | Verified level-one spell profile |
| Searing Smite | Ignition survives a zero-HP result or defensive prompt; recurring save uses the actual Constitution roll mode | Resumable turn-start damage/save queue and higher-level casting |
