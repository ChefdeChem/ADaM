# Five Breath Weapon import gates

This slice completes five bounded checks before an imported 2014 Dragonborn Breath Weapon can inherit ADaM's verified executable mechanic.

1. The sheet must state that using the Breath Weapon costs an Action.
2. The area must be an exhalation originating from the character.
3. Every creature in the area must make the saving throw, preserving friendly-fire behavior.
4. The sheet must state that the verified damage applies on a failed save.
5. The sheet must state that a successful save takes half damage.

These checks complement the existing gates for save DC and ability, damage formula and type, area shape and size, use count, and rest recovery. Missing or contradictory text leaves the imported feature visible but descriptive and inactive; ADaM does not fill in an unstated rule from a name alone.

The verified Surina record remains a 2014 build. Its complete user-preserved Breath Weapon description now supplies the evidence required by the linker, while encounter resolution continues to use the already tested current-resolution area workflow.

Registry coverage remains **98 fully supported, 0 partial, and 1 descriptive**, totaling 99. These import safeguards do not reclassify registry entries. Control Flames remains descriptive.

Rules authority: official SRD 5.1, Dragonborn Breath Weapon.
